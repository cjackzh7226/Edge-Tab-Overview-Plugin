# 页览 · 标签页预览

适用于桌面版 Microsoft Edge 的自用扩展，版本 1.2.2。

本次修改：横向从两列增加为三列。普通网页浮层加宽到 1051 像素，以保持原有卡片尺寸；特殊页面的兼容菜单在浏览器允许的最大 800 像素宽度内显示三列。高度、微透圆角、字号和已有交互不变，不增加权限。

在 `edge://extensions/` 点击本扩展的重新加载按钮，然后刷新当前普通网页，再点击图标即可使用新版。

## 安装（约一分钟）

1. 如果使用压缩包，先完整解压到一个打算长期保留的文件夹。
2. 在 Edge 地址栏输入 `edge://extensions/` 并回车。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择 **edge-tab-overview** 文件夹。这一层直接包含 `manifest.json`，不要选择外层目录，也不要直接选择 ZIP 文件。
5. 点击 Edge 右上角的“扩展”按钮，在“页览 · 标签页预览”旁选择“在工具栏中显示”（部分版本显示为图钉）。
6. 点击工具栏的方框数字图标，即可展开标签页菜单。

本次交付可直接选择的目录：`D:\Vibe C\小插件\edge-tab-overview`。

安装完成后请保留此文件夹。需要移动文件夹时，请从新位置重新加载。无须注册账号、启动服务器或安装 Node.js。

## 怎么使用

- 只显示点击扩展图标所在窗口的标签页；图标中的数字表示该窗口的标签页数量。
- 点击工具栏图标后，在普通 HTTP/HTTPS 网页的右上角显示浮层。浮层直接叠在真实网页上，背景能透出底下的内容，四角也真实裁切。
- 入口在后台直接选择最终菜单，不先显示长方形“正在读取标签页”窗口。浮层准备期间不会展示未完成的界面。
- Edge 新标签页、扩展管理页、其他扩展的页面及拒绝注入的页面，自动使用普通扩展菜单；兼容菜单没有网页透出效果，外部窗口形状由浏览器控制。你截图中的新标签页属于需要重点留意的兼容场景，请到普通网页体验真微透。
- 三列卡片，上方为网站图标和标题，下方为 16:9 横向预览。悬停卡片可以看完整标题和网址。
- 普通网页浮层宽度为 1051 像素，窗口不够宽时自动收窄；兼容菜单最多 800 像素，因此兼容模式或窄窗口中的卡片会相应缩小。普通尺寸下的浮层保持上一版卡片大小、字号与按钮大小。高度优先用满允许的空间，更多内容在卡片区域内部滚动。搜索框和底部按钮固定保留；数量少时菜单自动变矮。
- 点击卡片切换标签页，菜单继续可用，并保留搜索词及滚动位置；当前页有蓝色边框。
- 点击卡片右上角的 × 关闭该标签页，菜单更新。关闭最后一个标签页时，Edge 会关闭该窗口，菜单也随之结束。
- 搜索框按标题和网址筛选；底部 + 新建并切换到标签页，同时保留菜单和现有搜索条件。新建页不符合搜索条件时，清空搜索即可看到它。
- 点击菜单外部可以收起菜单。Esc 优先清空搜索，没有搜索词时收起；Ctrl+F 将焦点移到搜索框。
- 配色跟随浏览器向扩展提供的深浅模式偏好。普通网页浮层使用半透明底色、真实背景模糊、细边高光和柔和阴影；网页预览和文字保持清晰。浏览器自定义主题的配色不逐色复刻。

## 预览画面如何更新

预览是最近浏览画面，不是所有后台页面的实时视频。

- 页面加载、切换到可见页面、滚动停下、调整窗口尺寸时适时刷新。
- 普通网页可见期间约每 6 秒再刷新一次，以反映动态内容；请求经过限流处理。
- 打开菜单时尝试刷新当前页。后台页保留最近一次可见时获取的画面。
- 网页浮层显示期间暂停截图，防止把菜单本身截入预览；关闭浮层后继续更新。切换页面时先尝试获取目标页画面，再显示浮层。
- 只获取网页可见区域，按 16:9 裁切；不拉伸，也不截取整个长网页。
- 未获取预览时显示“浏览后显示预览”。Edge 内部页面、扩展页面、休眠页或权限受限页面可能无法预览，仍可搜索、切换和关闭。
- 第一次安装时，已打开但未重新加载的网页尚未运行滚动监听。切换到这些页面仍会尝试预览；刷新该网页后，滚动和定时更新开始生效。

## 临时数据与权限

预览使用浏览器的 `storage.session` 会话内存，不生成用户图片文件，不写入 `storage.local` 或同步存储，也不上传预览。关闭标签页会删除对应画面；彻底退出并重启浏览器、禁用或重新加载扩展也会清除。Edge 若仍在后台运行，关闭所有窗口不一定等于退出浏览器。

预览采用约 7 MB 的保守内存预算，达到预算时优先释放最久未更新的画面；对应标签页仍保留，可以在再次浏览后获取新预览。

安装时会显示网站访问相关权限，这是自动获取当前可见网页预览所需：

| 权限 | 用途 |
| --- | --- |
| tabs | 获取标题、网址、网站图标，以及管理标签页 |
| storage | 临时保存会话预览和菜单恢复状态 |
| activeTab | 用户点击扩展后获取当前页的临时访问权限 |
| scripting | 在允许的普通网页中放置浮层，不更改网页的业务内容 |
| 所有网址 | 在正常浏览过程中更新当前可见网页的画面 |

网页内的小脚本只发送“页面可见/滚动/尺寸变化”通知，不读取表单、密码或网页文本。网页画面本身可能包含你正在看的内容，因此预览仅在本次会话临时使用。扩展不包含分析统计或截图上传服务。网站图标使用标签页自身提供的地址。

## 已知边界

- **切换后的菜单延续通过自动恢复实现。** 切换后在目标页恢复浮层或兼容菜单，并恢复搜索和滚动位置。目标页加载、截图和入口切换可能造成短暂延迟或重绘。
- **放大后的可见排数减少。** 标准弹窗最高 600 像素，浏览器还可能根据屏幕可用空间降低上限，所以无法把宽高同时翻倍。本版优先保留大卡片，通过缩短内部滚动区域适配高度，不再为了同时塞下四排而缩小卡片。正常高度下约可看两排；较小屏幕可能只能完整显示一排及下一排的一部分。
- **普通网页与特殊页面的效果不同。** 普通网页浮层能真实透出并模糊网页，圆角外没有矩形底板。兼容菜单仍是浏览器创建的原生窗口，不支持靠 CSS 穿透到后方网页；本版去掉了其内部伪圆角外露的底板边缘，采用一致的直边外壳，不再把它声称为真透明窗口。
- **不是切走前最后一帧的保证。** 自动更新有短暂延迟，后台网页无法通过普通截图接口连续实时更新。
- 工具栏数字最多显示 `999+`；菜单底部和图标悬停提示显示实际总数。
- 本版本不处理无痕窗口、分组管理、非活动项整理或跨设备同步。

## 更新与排查

替换扩展文件后，在 `edge://extensions/` 点击该扩展的重新加载按钮；已有网页需要刷新才能使用更新后的页面监听脚本。

如果菜单打不开，请检查扩展是否已启用。如果预览暂时空白，先实际浏览一个普通网页，等待一小会儿再打开菜单；休眠页面需要先切换过去唤醒。若是受限页面，则保留占位图。

验证记录：在 Microsoft Edge 153.0.4234.32 中使用独立测试配置完成 46 项检查。通过浏览器调试协议触发扩展图标点击，并监听原生弹窗创建，确认普通网页首次打开和连续切换不创建中转弹窗，兼容菜单关闭后不残留入口绑定。浅色、深色模式仍通过真实网页背景像素比较验证透明性；同时覆盖已有交互、访问令牌和预览排除浮层。完整结果位于交付目录 `tests/results/integration.json`。测试使用本地示例网页，不读取你的个人浏览器资料。

## 开发文件

- `manifest.json`：扩展声明与权限。
- `background.js`：标签页事件、截图、会话数据、工具栏数量和弹窗恢复。
- `activity.js`：网页可见活动通知。
- `overlay.js`：网页内真实微透浮层、圆角裁切、点击外部关闭及窗口尺寸适配。
- `popup.html`、`popup.css`、`popup.js`：卡片菜单。
- `icons/`：工具栏图标与缺省网站图标。

技术依据：[Edge 扩展 API](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/api-support)、[弹窗行为](https://developer.chrome.com/docs/extensions/develop/ui/add-popup)、[截图接口](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)、[会话存储](https://developer.chrome.com/docs/extensions/reference/api/storage#property-session)。
